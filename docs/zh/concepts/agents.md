# 智能体 (Agents)

智能体是将语言模型、上下文和工具结合起来以执行多步开发任务的编排层。LLM 生成文本，而智能体能够自主地规划、执行、验证和迭代。

## 智能体循环 (Agent Loop)

智能体模式背后的核心机制：

```
用户提示词
    ↓
┌─────────────────┐
│ 组装上下文       │ ← 文件、历史、指令、工具输出
│ 调用 LLM        │
│ 执行工具        │ → 读取文件、编辑代码、运行终端、搜索
│ 检查结果        │
└────────┬────────┘
         │ 未完成
         └──→ 继续循环
```

每次迭代：智能体组装上下文 → 调用模型 → 执行工具 → 将结果反馈回去。此过程持续进行，直到任务完成或智能体需要你的输入。

## 智能体类型

VS Code 支持三种类型的智能体，在交互性、速度和隔离性之间做出不同的权衡：

| 类型 | 运行位置 | 最适用于 |
|---|---|---|
| **本地智能体** | VS Code 内部 | 交互式工作、快速迭代、完整的工具/扩展访问权限 |
| **后台智能体 (Copilot CLI)** | 本地机器、VS Code 外部 | 定义明确的、可自主运行的任务 |
| **云端智能体** | 远程基础设施 (GitHub) | 团队协作、基于 PR 的工作流、大规模重构 |

### 本地智能体

在编辑器中运行，完全访问工作区、工具和扩展。内置的本地智能体：

- **Agent** — 通用模式，具有完整工具访问权限的多文件编辑
- **Ask** — 只读问答模式，不修改文件
- **Plan** — 在实施前进行结构化规划（参见 [规划](/zh/agents/planning)）

### 后台智能体 (Copilot CLI)

使用 Copilot CLI 在本地机器上独立运行。从聊天视图创建会话或从本地智能体切换。支持工作树 (Worktree) 隔离以防止干扰你的当前工作。参见 [Copilot CLI](/zh/agents/copilot-cli)。

### 云端智能体

在远程基础设施上运行（如 GitHub Copilot 编码智能体）。创建拉取请求并与团队审查工作流集成。参见 [云端智能体](/zh/agents/cloud-agents)。

## 子智能体 (Subagents)

子智能体是独立的 AI 智能体，执行专注的工作并将结果报告给主智能体。它们提供 **上下文隔离** — 子智能体在自己的上下文窗口中工作，保持主对话的整洁。

关键模式：
- **实施前研究** — 将调研工作委派给子智能体
- **并行代码分析** — 同时运行多个分析
- **多角度审查** — 每个审查视角在其自己的子智能体中

详见 [子智能体](/zh/agents/subagents)。

## 记忆 (Memory)

智能体使用记忆在对话之间保留上下文：

- **用户记忆** — 跨所有工作区持久化（偏好、模式）
- **仓库记忆** — 限定于当前工作区（规范、构建命令）
- **会话记忆** — 限定于当前对话（任务相关笔记）

详见 [记忆](/zh/agents/memory)。

## 在智能体类型之间切换

你可以在不同类型的智能体之间切换会话：

- **本地 → Copilot CLI** — 在本地规划，在后台实施
- **本地 → 云端** — 在本地规划，通过 PR 实施
- **Copilot CLI → 云端** — 使用 `/delegate` 将任务交给云端

完整的对话历史和上下文将被保留。
