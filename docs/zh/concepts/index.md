# 核心概念

了解 GitHub Copilot 背后的核心概念有助于你更有效地使用它。本节涵盖了 VS Code 中 AI 辅助开发的基础思想。

## 你将学到

- **[语言模型](./language-models)** — LLM 是如何工作的，什么是上下文窗口，以及如何为任务选择正确的模型。
- **[上下文 (Context)](./context)** — VS Code 如何为每个请求组装上下文，以及如何提供正确的信息。
- **[工具 (Tools)](./tools)** — 模型操作开发环境的机制 —— 读取文件、运行命令以及连接外部服务。
- **[智能体 (Agents)](./agents)** — 使用 LLM 和工具自主执行多步开发任务的编排层。
- **[自定义 (Customization)](./customization)** — 为你的项目量身定制 AI 行为的框架 —— 指令、提示词、技能、智能体、MCP、钩子和插件。

## 宏观图景

```
你 (提示词) → 智能体 → LLM + 上下文 + 工具 → 响应
                 ↑
             自定义层
    (指令、技能、智能体、MCP、钩子)
```

1. 在聊天视图中向**智能体**发送**提示词**。
2. 智能体组装**上下文**（文件、历史、指令、工具输出）并将其发送给**语言模型**。
3. 模型对任务进行推理，并决定调用哪些**工具**。
4. 工具输出反馈到上下文中，进行下一次迭代（**智能体循环**）。
5. 你的**自定义配置**（指令、提示词文件、自定义智能体、MCP 服务器、钩子）塑造了这一过程的每一步。
