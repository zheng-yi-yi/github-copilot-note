# GitHub Copilot Note

A comprehensive, practical guide to mastering GitHub Copilot in Visual Studio Code. This repository contains the source code for a documentation site built with [VitePress](https://vitepress.dev/).

## 📖 Content Overview

This guide covers everything from foundational concepts to advanced agent workflows and deep customization:

- **🧠 Concepts**: LLMs, Context Windows, Tools, and the Agent Loop.
- **🤖 Agents**: Planning, Memory, Subagents, Copilot CLI, and Cloud Agents.
- **⚙️ Customization**: Custom Instructions, Prompt Files, Agent Skills, Custom Agents, MCP Servers, Hooks, and Plugins.
- **✅ Best Practices**: Effective Prompting, Security, and Plan-First Workflows.

## 🚀 Getting Started

### Local Development

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm run docs:dev
   ```

3. **Open in browser**:
   Navigate to `http://localhost:5173` to view the documentation.

### Build and Preview

1. **Build the static site**:
   ```bash
   npm run docs:build
   ```

2. **Preview the production build**:
   ```bash
   npm run docs:preview
   ```
